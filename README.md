# Imam Hussain (A.S.) — Editorial Website V2

A premium editorial Islamic knowledge website built with React 19, Vite 8, and Tailwind CSS v4.

## Tech Stack
- React 19 + TypeScript
- Vite 8 with HMR
- Tailwind CSS v4
- DM Serif Display + Inter + Manrope fonts

## Pages
- **Homepage** — Hero, Topics, Featured Articles, Philosophy Panel, New Articles, Karbala & Ziarat
- **Category Page** — Filtered article listings per category
- **Article Page** — Full article with related posts

## Categories
Imam Hussain · Muharram · Karbala · Companions · Arbaeen · Ziarat · Lessons · Resources

## Setup
```bash
pnpm install
pnpm dev
```

> Note: Image assets are served from Figma CDN. Add your own images to `src/imports/` to replace them.

## WordPress Theme
The `imam-hussain-theme-V1.zip` WordPress theme is included. Install via Appearance → Themes → Upload.
